# Mental Health Support Telegram Bot

A Telegram bot designed to provide mental health support through conversation, resources, and simple exercises.

## Features

- Conversational support using AI
- Mental health resources
- Random mental health tips
- Conversation memory to provide context-aware responses

## Deployment on Vercel

This bot is designed to be deployed on Vercel:

1. Fork or clone this repository
2. Connect it to your Vercel account
3. Add your `TELEGRAM_BOT_TOKEN` as an environment variable in Vercel
4. Deploy the project
5. After deployment, visit `https://your-vercel-app.vercel.app` to confirm the webhook is set up

## Commands

- `/start` - Start or restart the conversation
- `/help` - Show help information
- `/reset` - Reset conversation history
- `/resources` - Get mental health resources
- `/tip` - Get a random mental health tip

## Important Note

This bot is not a replacement for professional mental health support. If you or someone you know is in crisis, please contact a mental health professional or crisis service immediately.
